\# Truzon ID Generator (PHP)



Simple PHP tool to generate ID cards:

\- Upload a photo

\- Enter Name + Designation

\- Get a PNG ID in `/output`



\## Run locally

\- PHP 8.x with GD extension

\- Place your template at `template/template.png`

\- Open `index.html` in browser (served by PHP or Apache/Nginx)



\## Deploy

\- Any PHP host (Azure App Service recommended)

\- See “Deploy to Azure” below
